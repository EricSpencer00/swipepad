# Third-party provenance

- `Sources/TrackpadBridge`: Objective-C framework source from [OpenMultitouchSupport](https://github.com/Kyome22/OpenMultitouchSupport), tag 3.0.0, commit `5f478ff6a14602415c11e34080ce2695c1f19fc0`. MIT, copyright 2019 TakutoNakamura. Full notice: `ThirdParty/OpenMultitouchSupport-LICENSE`. Vendored source only, no binary download. Modified framework includes for SwiftPM, removed device-identifying diagnostic logging, guarded null devices and failed starts, cleared released device pointers, limited wake restart to active listeners, and dispatched callback handling to main for serialized listener access, and rejected queued frames from earlier listening sessions. No upstream Swift wrappers or binary targets are used.
- `Sources/SwipepadCore/Core.swift`: keyboard layout and two-row dynamic-time-warping recurrence adapted to Swift and normalized geometry from [SwipeType](https://github.com/ZimengXiong/swipeType), commit `e07a986398e3a424f9413d2f5ec44cc5833d0388`, `crates/swipe-engine/src/keyboard.rs` and `dtw.rs`. MIT, copyright 2026 Zimeng Xiong. Full notice: `ThirdParty/SwipeType-LICENSE`. SwipeType's physical-keyboard capture and word-frequency data are not included.

The small demonstration vocabulary is original to this project. No external models or wordlist are redistributed. There are no network package dependencies. Apple's system frameworks are linked from the installed SDK/system; MultitouchSupport is private and has no public compatibility guarantee.
